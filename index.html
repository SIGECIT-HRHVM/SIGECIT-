Acerca del proyecto

Nombre: SIGCT-HRHVM — Sistema Integrado de Gestión y Control de Turnos del Hospital Regional Hermilio Valdizán Medrano.

Tipo: Prototipo académico para el curso de Innovación II.

Problema que busca abordar: las dificultades que pueden producirse cuando la programación de citas, el control de turnos y la información administrativa se gestionan mediante procesos poco integrados.

Propuesta de valor: reunir en una interfaz los procesos de registro, consulta y seguimiento, con el propósito de facilitar la organización y contribuir a una atención más oportuna.

Beneficiarios: pacientes, personal de admisión, personal asistencial y administración hospitalaria.

Esta página es una demostración visual y funcional. No representa una plataforma oficial del Hospital, no ofrece citas reales y no almacena historias clínicas. Para uso real se necesitarían autorización institucional, análisis de seguridad, protección de datos personales, validación clínica y un servidor seguro.
